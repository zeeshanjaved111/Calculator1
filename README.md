# 🧮 Calculator1

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Live Demo

🔗 Live Website:
https://zeeshanjaved111.github.io/Calculator1/

## 📌 Features

- ✅ Addition (+)
- ✅ Subtraction (-)
- ✅ Multiplication (*)
- ✅ Division (/)
- ✅ Clear button functionality
- ✅ Responsive design
- ✅ Simple and clean user interface
- ✅ Fast and lightweight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
